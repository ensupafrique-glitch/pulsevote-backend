# PulseVote AI Backend Starter

Backend NestJS modulaire pour une plateforme de sondages multi-tenant avec PostgreSQL, Prisma et BullMQ.

## Stack
- NestJS
- Prisma + PostgreSQL
- BullMQ + Redis
- JWT auth
- RBAC + contexte tenant
- OpenAPI Swagger

## Modules
- auth
- organizations
- users
- memberships
- surveys
- votes
- comments
- notifications
- trends
- ai-generation
- analytics
- audit

## Commandes visées
- `pnpm install`
- `pnpm prisma generate`
- `pnpm prisma migrate dev`
- `pnpm start:dev`
